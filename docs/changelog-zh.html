v1.5.0 2026年1月20日

🤖 智能功能

  • 智能 API 密钥检测：根据 API 密钥格式自动识别 AI 服务商（OpenAI、Anthropic、Gemini、DeepSeek）
  • 自动配置：检测到密钥后自动切换服务商并填充默认 API URL 和模型
  • 内联反馈：识别 API 密钥时实时显示服务商和模型信息的视觉确认
  • 完整 i18n 支持：所有检测反馈消息支持 10 种语言本地化

🎨 UI/UX 改进

  • 重组设置：API 密钥字段移到设置顶部，优化工作流程
  • 视觉反馈：绿色渐变通知框显示检测到的服务商和配置的模型
  • 警告消息：当 API 密钥格式无法识别时显示黄色通知
  • 自动隐藏：通知在 8 秒（成功）或 5 秒（警告）后自动消失
  • 尊重用户设置：当检测到的服务商与当前选择匹配时，保留用户的自定义配置

🌐 国际化

  • 10 种语言：检测反馈支持英语、中文（简体和繁体）、日语、韩语、德语、西班牙语、法语、荷兰语、乌克兰语

v1.0.1 2026年1月8日

🔧 更改

  • 在manifest.json中添加了clipboardWrite权限，以明确剪贴板访问权限
  • 提高了商店审核流程的权限清晰度

📋 技术细节

  • 扩展使用剪贴板API自动将AI处理的文本复制到剪贴板
  • 以前仅依赖scripting权限来注入剪贴板访问代码
  • 现在明确声明clipboardWrite权限以提高透明度

✨ 为什么要做这个更改？

  • 清晰度：在权限列表中明确剪贴板使用
  • 合规性：确保完全符合商店要求
  • 面向未来：为service worker中潜在的直接剪贴板API访问做准备
